# אטימות אמיתית: Secure Boot ביצרן (מפתח משלך) — M36 / MT6765

> עדכון ל-`kosher_hardening.md`: נכון שאי אפשר "לחסום צריבה" ע"י מחיקת קבצים או השחתת preloader.
> אבל יש תהליך תקני של יצרנים שעושה בדיוק את זה: **Secure Boot של MediaTek עם מפתח היצרן שלך**.

## איך זה עובד
1. **eFuse root key hash (SBC_EN)** – ב-OTP של השבב נצרב hash של המפתח הציבורי שלך. חד-כיווני.
2. **BROM מאמת את ה-preloader** מול המפתח. preloader לא חתום על ידך – השבב לא מריץ אותו.
3. **SLA/DAA** – ה-BROM מקבל Download Agent רק אם הוא חתום. בלי המפתח/קובץ ההרשאה שלך
   SP Flash Tool לא צורב כלום, **גם לא את הרום המקורי של היצרן** (הוא חתום במפתח אחר).
4. **שרשרת**: preloader → lk → tee → vbmeta/boot, AVB עם מפתח **שלך**, bootloader נעול, rollback index.
5. **מערכת**: build מסוג user, ללא adb, `ro.debuggable=0`, SELinux enforcing, OEM unlock כבוי.

התוצאה: רק מי שמחזיק במפתח החתימה שלך יכול לצרוב.

## מה צריך
- כלי Secure Boot / signing של MediaTek לשבב (מגיעים דרך MTK או ספק הלוחות; לא ציבוריים).
- זוג מפתחות RSA משלך, שמור אופליין, גיבוי מוצפן ב-2 מקומות לפחות (רצוי HSM/כרטיס חכם).
- תהליך חתימה לכל image: preloader, lk, tee, vbmeta (+ boot/super דרך AVB).
- 2–3 יחידות ניסוי מוקרבות לפני כל מכשיר מהמלאי.

## סיכונים לתכנון
- **eFuse בלתי הפיך**: חתימה או מפתח שגויים = מכשיר מת. ייצור רק אחרי ששרשרת מלאה עלתה ביחידת ניסוי.
- **אובדן מפתח = אובדן הצי** (גם עדכונים לא יהיו אפשריים).
- **לוח שכבר ננעל במפתח זר** במפעל – אי אפשר להחליף. לבדוק ביחידת דגימה לפני רכישה בכמות.
- **גבול השבב**: ב-MT67xx מסוימים קיימות חולשות BROM ציבוריות שעלולות לעקוף את שלב האימות.
  לבדוק את השבב המדויק. מול הלקוח לנסח "דורש יכולת מעבדה", לא "בלתי אפשרי".
- אל תשחית preloader ואל תשרוף fuses אקראיים – זה לא Secure Boot, זה בריק.

## צעדים
1. לאשר שבב ויצרן preloader (נתונים ב-`avb.json`, `BOOT_CHAIN.md`).
2. להשיג את חבילת ה-secure boot tooling.
3. יחידת ניסוי: יצירת מפתחות → חתימה → צריבה → burn → אימות שצריבת רום מקורי נדחית.
4. לבנות super נקי (הסרת רשת מהבסיס, `removal_recipes.json`) ולחתום באותו מפתח AVB.
5. תהליך ייצור: סקריפט חתימה + צריבה + בדיקת איכות + תיעוד גיבוי מפתח.
