# Android ROM Atlas

תיעוד מלא של רומים לאנדרואיד: מה בונה מה, מה תלוי במה, ואיזה רכיב גורם למה.
כל רום מקבל אתר תיעוד משלו.

- `tools/` – כלים לפירוק וניתוח (נכתבים בפרויקט עצמו)
- `roms/<device>/<rom>/` – תוצאות ניתוח לכל רום (מטא-דאטה בלבד, ללא קבצי מערכת)
- `docs/` – מאגר ידע כללי ואתרי התיעוד

מדיניות: קבצי מערכת (APK, ספריות, images) ומידע מזהה (IMEI, nvram, nvdata, proinfo, protect) לא נשמרים בריפו.
